# Servizio Giornaliero – ExtraUrbano (Python/Streamlit)

Porting della macro Excel in Python:
- parsing robusto dell'header (cerca "Cognome e Nome"),
- filtri su matricole e turni da omettere (config CSV),
- rinomina residenze,
- sostituzione sigle di assenza in colonna `Stato`,
- ordinamenti configurabili,
- riepilogo per sigle assenza,
- export Excel e PDF.

## Requisiti

Python 3.11+
